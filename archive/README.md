# Superseded and exploratory data

These gzip files retain the early query outputs for reproducibility and transparency. They are NOT the final citywide analysis inputs. Early subsets cover a smaller area; some OSM responses are stale cached snapshots. In particular, superseded/osm-crossing-nodes.json.gz reports an OSM base timestamp of 2026-06-01T08:52:28Z. Never combine these with the October snapshot and call them current.

Authoritative data: ../data/snapshot-2026-10-27/. Public-data privacy filtering and licences are described in ../data/README.md and ../DATA-LICENSES.md. City website HTML, photographs and private correspondence are not redistributed; source URLs are preserved in ../review/sources.json.
