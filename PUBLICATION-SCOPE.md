# Publication scope

This repository contains the final English review material, bilingual local workflow, diagrams, runnable portable refresh/comparison code, reviewed-node export code and tests, the complete citywide public-data inputs, local API verification inputs, and labelled exploratory data. It was prepared with Codex at the repository owner's request.

Excluded: mailbox contents, delivery receipts, account identifiers unrelated to public OSM data, local author paths, authentication material, failed-run logs, generated synthetic edit files, duplicated intermediate packages, and City webpage/photo copies whose independent redistribution terms were not established. The original source URLs remain available for review.

Municipal created_user, last_edited_user and OWNER fields were omitted across raw datasets and nested review attributes; no geometry or comparison key/value depends on those fields. Public OSM usernames/UIDs in OSM API snapshots are retained as source metadata.

The complete original analysis is represented by final candidate results and portable scripts. Obsolete one-off download/debug scripts with author-specific paths are replaced by the maintained refresh workflow. Archived data are explicitly excluded from current findings.

Uploading this project to GitHub does not upload to OpenStreetMap. No preapproved physical corrections, independent field survey, OSM-compatible City import permission, or completed community import review are claimed.
